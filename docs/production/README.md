# Production Module

## Описание

Модулът "Производство" позволява отчитане на производствени процеси, включително:
- Регистриране на производствени операции
- Отчитане на използвани материали
- Следване на складови движения (изписвания и вписвания)
- Анализ на производствените данни

## Основни компоненти

### 1. Production Entity
Основен клас за производствените операции:
- `name` - име на производствената операция
- `description` - описание
- `product` - произведен продукт
- `quantity` - планирано количество
- `startDate` - начална дата
- `endDate` - крайна дата
- `materials` - свързани материали (OneToMany)
- `stockMovements` - складови движения (OneToMany)

### 2. ProductionMaterial Entity
Отчита използваните материали:
- `production` - свързана производствена операция
- `material` - използван материал (Product)
- `quantity` - количество

### 3. ProductionStockMovement Entity
Следва складовите движения:
- `production` - свързана производствена операция
- `product` - продукт
- `warehouse` - склад
- `quantity` - количество
- `movementType` - тип движение (IN/OUT)
- `notes` - бележки

### 4. ProductionMovementType Enum
Дефинира типовете движения:
- `IN` - вписване в склад
- `OUT` - изписване от склад

## Функционалности

### Основни CRUD операции
- Създаване на производствена операция
- Редактиране на производствена операция
- Изтриване на производствена операция
- Списък с производствени операции

### Търсене и филтриране
- Търсене по име на операция
- Търсене по продукт
- Филтриране по дати (начална/крайна)
- Сортиране по дата на създаване

### Складови операции
- Автоматично изписване на материали при регистриране
- Автоматично вписване на готов продукт
- Проверка за достатъчно количество в склада
- Следване на всички складови движения

## Service класове

### ProductionService
Предоставя бизнес логика за:
- `registerMaterialConsumption()` - регистрира изписване на материали
- `registerProductOutput()` - регистрира вписване на готов продукт
- `getTotalMaterialConsumption()` - изчислява общо използвани материали
- `getTotalProductOutput()` - изчислява общо произведен продукт

## Бъдещи разширения

Модулът е проектиран за лесно разширяване с:
- Производствени рецепти (BOM - Bill of Materials)
- Планиране на производство
- Анализ на ефективността
- Интеграция с други модули (закупки, продажби)
- Отчитане на работно време
- Контрол на качеството
- Следване на разходите

## Интеграция

Модулът се интегрира с:
- **Product модул** - за продукти и материали
- **Warehouse модул** - за складови операции
- **User модул** - за отчитане на потребители

## Конфигурация

Модулът използва стандартните конфигурации на системата:
- Doctrine ORM за данни
- Symfony Forms за форми
- Twig за шаблони
- Translation система за преводи
